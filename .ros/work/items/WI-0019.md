# WI-0019: Administrator sandbox, synthetic data, advanced analytics extensions, and phase boundary

Status: captured  
Source authority: `input-documents/survey-engine-administrator-console-storage-analytics-visualization-requirements.txt`

## Objective

Provide a safe experimental environment for previewing and stressing the administrator system while protecting phase-1 scope and canonical result authority.

## Reciprocal source requirement references

Every actionable statement in each cited ADM requirement group is in scope for this work item.

| Group | Section | Requirement represented |
|---|---|---|
| ADM-039 | Optional Advanced Analytics Extensions | Future clustering/anomaly/benchmark/AI-derived analysis kept outside deterministic scoring authority. |
| ADM-040 | Phase Boundaries | Phase-1 browser/GitHub scope and explicit non-requirement of a custom server/background infrastructure. |
| ADM-042 | Administrator Sandbox and Simulation Mode | Hard isolation of synthetic/test administration state from live accepted state. |
| ADM-043 | Synthetic and Adversarial Survey Data Generator | Seeded reproducible generators for valid, boundary, malformed, privacy, scale, and pathological fixtures. |

## Acceptance criteria

- [ ] Implement a clearly isolated sandbox that cannot accidentally promote synthetic accepted results into live groups.
- [ ] Implement reproducible seeded synthetic/adversarial generation with generator version/profile/provenance.
- [ ] Use synthetic fixtures for report, visualization, privacy, performance, storage, and accessibility preview/testing.
- [ ] Preserve the phase-1 no-server boundary while keeping future advanced/probabilistic analytics explicitly derived and non-authoritative.
- [ ] Label every sandbox/synthetic/AI-derived artifact so it cannot be confused with formal production evidence.
