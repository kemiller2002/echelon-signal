## Acceptance criteria

- [ ] Implement the explicit parse/resolve/verify/decode/validate/evaluate/score/accept pipeline with stable import errors.
- [ ] Enforce one accepted contribution per identified SurveyInstanceId or AnonymousSubmissionId; rejected/duplicate submissions must not affect counts or scores.
- [ ] Produce deterministic SurveyResult, SurveyGroupResult, and minimal AdminReportState with sufficient identity state for future imports.
- [ ] Support explicit raw-submission retention policy without accidental URL leakage into logs/analytics/telemetry.
- [ ] Choose EmbeddedInUrl versus ExternalStore by encoded state size with safety margin; persistence mode must not alter logical report state or meaning.
