## Acceptance criteria

- [ ] Implement all ADM-036 stress scenarios with failure injection where needed and record unavailable evidence explicitly rather than treating it as pass.
- [ ] Run property/model-based tests across legal/illegal administrator transitions, import ordering, storage round trips, migration, privacy, and snapshots.
- [ ] Enforce explicit resource limits and prove bounded failure instead of browser freezes, unbounded recursion, or retry loops.
- [ ] Gate every StorageProvider on conformance evidence and every chart/report family on semantic/accessibility regression evidence.
- [ ] Prove end-to-end incremental invalidation/reprojection equals full reference rebuilding for supported transitions.
