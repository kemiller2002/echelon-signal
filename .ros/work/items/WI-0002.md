## Acceptance criteria

- [ ] Define serialization-neutral domain types for SurveyTemplate, SurveyInstance, SurveyResponse, SurveySubmission, SurveyGroup, SurveyResult, SurveyGroupResult, and AdminReportState.
- [ ] Make identifiers, lifecycle, compatibility, result shapes, coverage/confidence, source-of-truth boundaries, and invalid states explicit.
- [ ] Define F# module boundaries with encoding independent of UI and reporting dependent on result contracts rather than scoring internals.
- [ ] Record any material deviations from the authoritative source corpus in a Decision Record with reciprocal source references.
- [ ] Validate the contracts with representative simple, weighted, branching, maturity, and 360/group fixtures.
