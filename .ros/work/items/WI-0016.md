# WI-0016: Report builder, snapshots, exports, configuration packages, and policy packs

Status: captured  
Source authority: `input-documents/survey-engine-administrator-console-storage-analytics-visualization-requirements.txt`  
Migration ledger: `docs/requirements/survey-engine-requirements-migration.md`

## Objective

Turn authoritative analysis/report data into versioned report definitions, reproducible formal snapshots, safe exports, portable configuration, and reusable deterministic policy packs.

## Reciprocal source requirement references

Every actionable statement in each cited ADM requirement group is in scope for this work item.

| Group | Section | Requirement represented |
|---|---|---|
| ADM-020 | Data-Lineage Explorer | Report-value lineage integration and privacy-respecting traceability. |
| ADM-021 | Report Builder | Structured versioned report composition with validation and preview. |
| ADM-022 | Report Snapshots and Reproducibility | Immutable formal snapshots bound to exact result/report/comparison versions. |
| ADM-023 | Exports | JSON/CSV/print-HTML/PDF/offline projections from the same ReportData and privacy policy. |
| ADM-047 | Portable Configuration Packages | Provider-independent versioned configuration bundles without credentials or response data. |
| ADM-048 | Versioned Policy Packs | Reusable deterministic policy constraints for privacy/accessibility/reporting/storage/audit. |

## Acceptance criteria

- [ ] Implement report-definition authoring/versioning/preview without allowing presentation to override canonical scoring or aggregation.
- [ ] Create immutable report snapshots that reproduce historical ReportData even after current group/report state changes.
- [ ] Generate every export from the same authorized ReportData and enforce identical privacy/suppression rules.
- [ ] Implement integrity-protected configuration-package import/export with dry-run validation and provenance.
- [ ] Implement deterministic policy-pack resolution, inheritance/conflict handling, and snapshot provenance where relevant.
