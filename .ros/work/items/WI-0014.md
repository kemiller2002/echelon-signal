## Acceptance criteria

- [ ] Implement typed deterministic analysis expressions and metric prerequisites without changing canonical result authority.
- [ ] Implement semantic comparison eligibility with stable incompatibility reasons across template/scoring/aggregation versions.

- [ ] Prove targeted invalidation/recomputation equals full reference rebuilding for supported administrator transitions.
