## Acceptance criteria

- [ ] Implement the named V1 standard scorers and safe parameterization, with the advanced catalog available behind explicit authoring choices.
- [ ] Implement only a constrained typed/versioned custom AST as an escape hatch; reject arbitrary executable code, reflection, and runtime compilation.
- [ ] Support question, section, survey, group, scalar, categorical, profile, and composite semantics with explicit direction and missing/special-state policies.
- [ ] Separate scoring, aggregation, interpretation, coverage, confidence, selectors, and rendering.
- [ ] Provide reproducible diagnostics and compatibility/characterization tests for existing survey behavior before any source JSON migration.
