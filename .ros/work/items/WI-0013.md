# WI-0013: Administrator import, concurrency, durable aggregation, and indexes

Status: captured  
Source authority: `input-documents/survey-engine-administrator-console-storage-analytics-visualization-requirements.txt`  
Migration ledger: `docs/requirements/survey-engine-requirements-migration.md`

## Objective

Make accepted submissions a deterministic immutable set with safe concurrent import, incremental aggregation, rebuildable indexes, and explicit reconciliation of uncertain external effects.

## Acceptance criteria

- [ ] Implement the authoritative import pipeline and batch intake without allowing rejected/duplicate artifacts to affect counts or scores.
- [ ] Persist accepted contributions immutably and update mutable manifests only with compare-and-swap/version evidence.
- [ ] Prove independent import order does not change final accepted set or SurveyGroupResult.
- [ ] Implement incremental aggregation and verify equality to full reference recomputation for generated sequences.
- [ ] Implement index/materialized-view validation, rebuild, comparison, activation, and corruption recovery.
