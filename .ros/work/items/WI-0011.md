# WI-0011: Administrator application state, group management, and Limen UX

Status: captured  
Source authority: `input-documents/survey-engine-administrator-console-storage-analytics-visualization-requirements.txt`  
Migration ledger: `docs/requirements/survey-engine-requirements-migration.md`

## Objective

Build the administrator application shell and domain lifecycle so all admin actions are explicit F# state transitions exposed through Limen, with no PII or duplicated browser authority.

## Acceptance criteria

- [ ] Model administrator/group state, commands, capabilities, obligations, read-only/degraded modes, and stable reason codes in F#.
- [ ] Implement group creation/configuration/status flows without permitting interpretation-changing mutation of accepted historical state.
- [ ] Implement the administrator navigation/information architecture, safe non-PII search/filter/saved views, and capability explanations.
- [ ] Keep TypeScript/browser code mechanical under Limen; prove no admin policy or domain decision is duplicated in the browser.
- [ ] Expose operational diagnostics and localization preview as projections of authoritative state/evidence.
