## Acceptance criteria

- [ ] Render only from authoritative SurveyResult/SurveyGroupResult/AdminReportState and never recreate applicability, validation, scoring, completion, deduplication, or anonymity logic.
- [ ] Implement versioned declarative report definitions, report data, audience/block/detail models, localization, rounding, missing states, warnings, and V1 report types.
- [ ] Enforce anonymous/identified privacy, minimum-count suppression, block classifications, and administrator-only identity joins.
- [ ] Permit comparisons only with explicit semantic compatibility and versioned benchmark provenance.
- [ ] Support deterministic HTML/print/PDF/JSON/CSV renderers as projections, plus optional reproducible snapshots and cache identity.
