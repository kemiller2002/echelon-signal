# WI-0015: Typed visualization grammar, dashboards, and accessibility

Status: captured  
Source authority: `input-documents/survey-engine-administrator-console-storage-analytics-visualization-requirements.txt`  
Migration ledger: `docs/requirements/survey-engine-requirements-migration.md`

## Objective

Create a reusable visualization system whose semantics come from F#, whose rendering can evolve independently, and whose accessibility and anti-misleading rules are mechanically testable.

## Reciprocal source requirement references

Every actionable statement in each cited ADM requirement group is in scope for this work item.

| Group | Section | Requirement represented |
|---|---|---|
| ADM-015 | Signal Visualization Grammar | Versioned declarative visualization specs owned/validated by F#. |
| ADM-016 | Visualization Suitability and Anti-Misleading Rules | Legal chart/data shapes, scale/missing/sort/privacy validation, and misleading-chart warnings. |
| ADM-017 | Visualization Accessibility | Screen-reader/table equivalents, keyboard access, contrast, non-color encoding, zoom/reflow, print/grayscale, low-vision and dyslexia considerations. |
| ADM-018 | Dashboard System | Versioned responsive dashboard definitions and composable deterministic blocks. |
| ADM-050 | Report and Visualization Regression Verification | Semantic/accessibility/responsive regression assertions with optional render snapshots. |

## Acceptance criteria

- [ ] Define VisualizationSpec and legal chart/data binding contracts for the required initial chart catalog.
- [ ] Validate suitability, scales, missing values, cardinality, privacy, direct labels, and deterministic sorting before rendering.
- [ ] Provide accessible semantic/table equivalents and keyboard/high-contrast/color-vision/zoom/print behavior for every supported chart type.
- [ ] Implement responsive versioned dashboard composition without duplicating business meaning in layout code.
- [ ] Establish semantic/accessibility regression fixtures for visualization and dashboard definitions.
