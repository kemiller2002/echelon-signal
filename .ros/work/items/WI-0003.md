## Acceptance criteria

- [ ] Support mutable drafts and immutable, resolvable published/superseded versions with stable lineage.
- [ ] Implement deterministic canonicalization, hashing, version assignment, dependency resolution, and rollback-as-new-version.
- [ ] Implement authoring, preview, simulation, semantic diffs, comparability assessment, localization, accessibility metadata, and no-PII safeguards.
- [ ] Block publication on the complete structural, rule, scoring, encoding, privacy, compatibility, URL-budget, and required-fixture failures in the mapped sources.
- [ ] Emit a reproducible validation/test manifest and preserve published template/test artifacts.
