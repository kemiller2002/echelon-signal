## Acceptance criteria

- [ ] Represent all required answer primitives and distinct unanswered, not-applicable, don't-know, and not-applicable-by-flow states.
- [ ] Implement versioned deterministic compact encoding and explicit template/envelope resolution errors; every valid state must round-trip.
- [ ] Continuously synchronize the current respondent state into the URL using history replacement and reconstruct the same state on reopen without server session persistence.
- [ ] Keep only non-reconstructable state in the URL; keep scoring/report data and template meaning out.
- [ ] Implement integrity/authenticity policy separation and portable identified/anonymous envelope variants consistent with WI-0005.
