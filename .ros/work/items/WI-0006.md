## Acceptance criteria

- [ ] Implement one small typed declarative rule model for flow, validation, derived facts, completion, and recommendations/actions.
- [ ] Validate identifiers, operand types, dependencies, reachability, and cycles before publication.
- [ ] Execute rules in a deterministic documented order with no mutable service, time, random, network, browser, or unversioned configuration dependency.
- [ ] Make applicability, answer/cross-question validation, completion/termination, and engine-owned recommendations explicit.
- [ ] Provide stable domain errors and an optional single-path evaluation trace.
